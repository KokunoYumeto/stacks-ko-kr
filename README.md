# Stacks Project 한국어 번역

[전체 116장 온라인으로 읽기](https://kokunoyumeto.github.io/stacks-zh-hans-cn/ko/index.html) · [언어와 판본 선택](https://kokunoyumeto.github.io/stacks-zh-hans-cn/)

영어 Stacks Project의 고정 판본 `a04446e57ec1fbc252a871afcec7752fb2807b14`에 대응하는
비공식 AI 보조 번역입니다. 공식 판본이 아니며 Stacks Project의 승인을 뜻하지 않습니다.
모든 장의 번역문은 있지만, 모든 표현의 용어 정규화나 전문가의 전면적인 인간 검토가
완료되었다는 뜻은 아닙니다. 대수기하학 전문가의 정정과 검토를 환영합니다.

보장하지 않습니다. 수식 표시에 필요한 고정 버전 구성 요소는 네트워크에서 불러옵니다.
지원하지 않는 일부 TeX는 코드로 보존합니다. 원래 PDF와 LaTeX도 함께 확인할 수 있습니다.

## 번역 선택의 근거와 검토

[번역 선택 색인](review/translation-choices/README.md)은 원문·번역문의 정확한 위치,
실제로 참조한 용어 사용례, 선택 이유, 대안 및 불확실성을 연결합니다.
직접적인 사용례, 간접 근거 및 모델에 따른 잠정 판단을 구분합니다.
공개 색인의 범위는 한정되어 있으며 전 장의 모든 표현이 검토되었다는 주장은 아닙니다.
영어 원문의 수학적 정정 제안과 독자적인 추가 내용은 번역 선택과 별도로 기록합니다.
이번 웹 공개는 장의 수학적 내용을 수정하지 않습니다.

GFDL 1.2 이상 조건을 계승합니다. 이전 공개 판본도 계속 이용할 수 있습니다.
이번 안내문과 웹 변환: OpenAI Codex — GPT-6 Astra, Ultra effort.
기존 번역과 수정의 제작 기록은 각 판본에 보존되어 있습니다. 이번 모델 표시가
모든 과거 번역에 사용된 모델을 뜻하지는 않습니다.
