It contains exactly Chapters 17, 60-68, 71, and 99 of the 116-chapter Stacks Project universe, in that order. It is a substantial partial edition, not a pilot, complete corpus, official Stacks Project publication, or independent Korean language certification.

The controlling English authority is `stacks/stacks-project` commit `a04446e57ec1fbc252a871afcec7752fb2807b14`. The twelve individual comparison files under `upstream/a04446e/` are included for bounded replay; no repository or authority archive is included. Suspected source errors remain in `errata/` as non-rendering sidecar evidence. Formula, label, and reference structures remain bound to the frozen authority.
